CARMAGEDDON (1997) - MS-DOS / WINDOWS 95 PC
========================================
THE EAGLE (MAX DAMAGE)
-------------------------------------------------------------------------------

Models ripped using Flummery: https://github.com/MaxxWyndham/Flummery
Textures ripped using CarmagEdit.

All the unlockable color variants of this vehicle are included:
BLACK EAGLE
BLUE EAGLE
GREEN EAGLE
EAGLE 1 (RED EAGLE)
WHITE EAGLE
YELLOW EAGLE

----------

Textures have been converted from PIX/TGA with pink = transparent,
to PNGs with alpha transparency.

Vertex colors have been saved as image textures.
Vertex colors differ between software (SW) and 3DFX Hardware (HW) mode,
so 2 separate textures are supplied.

BLACK EAGLE
* MURKHW (#212121)
* MURKSW (#3c3b3c)
